The Coefficient Choosing Game

Pick a commutative ring $R$ and a degree $d \ge 2$. Two players take turns filling in the coefficients of $a_d x^d + \cdots + a_1 x + a_0 \in R[x]$, in any order, with any element of $R$; only $a_0$ and $a_d$ can't be $0$. Once all $d+1$ are chosen, A(mog) wins if the polynomial has a root in $R$, and S(now) wins if it doesn't.

3

    Who wins?

    There are $d+1$ moves, so the first player also makes the last move when $d$ is even, and the second player does when $d$ is odd. Over the infinite rings here, the last move is nearly everything.

    Two rings where A can't lose

    \begin{proposition}Over $\C$, A always wins. Over $\R$ with $d$ odd, A always wins.\end{proposition}

    \begin{proof}The fundamental theorem of algebra, and the intermediate value theorem: a real polynomial of odd degree changes sign.\end{proof}

    Over the rationals, the last move wins

    \begin{theorem}\label{thm:q}Over $\Q$, whoever chooses the last coefficient wins. So the first player wins when $d$ is even and the second player wins when $d$ is odd.\end{theorem}

    \begin{proof}Say $a_k$ is the last coefficient and $q(x)$ is the rest of $p$. A nonzero $r$ is a root exactly when $a_k = \varphi(r)$, where $\varphi(r) = -q(r)/r^k$, and $0$ is never a root because $a_0 \neq 0$. If A moves last, A picks a rational $r \neq 0$ with $q(r) \neq 0$ and sets $a_k = \varphi(r)$, which isn't $0$. If S moves last: $a_0$ and $a_d$ are nonzero, so $\varphi$ is a rational function of degree $d \ge 2$, and by Hilbert's irreducibility theorem its values miss infinitely many rationals. S picks one of those that isn't $0$.\end{proof}

    The integers, almost

    \begin{proposition}\label{prop:z}Over $\Z$, if S chooses the last coefficient, S wins. If A chooses the last coefficient and it isn't $a_d$, A wins.\end{proposition}

    \begin{proof}If $a_k$ with $k \ge 1$ is last, every integer root divides $a_0$, which is already chosen. That leaves finitely many candidate roots, each ruling out one value of $a_k$, so S has plenty left, while A takes $r = 1$ and $a_k = -q(1)$. If $a_0$ is last, A takes any $r$ with $q(r) \neq 0$ and sets $a_0 = -q(r)$. S needs a nonzero integer that $-q$ never takes on $\Z$; $q$ has degree $d \ge 2$, so it takes only about $N^{1/d}$ of the values up to $N$.\end{proof}

    \begin{example}[The leading-coefficient trap]A can lose by moving last when the last coefficient is $a_d$. Take $p = a_3x^3 - x^2 + 1$: an integer root would divide $a_0 = 1$, but $p(1) = a_3$ and $p(-1) = -a_3$, and $a_3 \neq 0$. Amog knows this one.\end{example}

    The reals in even degree

    \begin{proposition}Over $\R$ with $d$ even, if A chooses the last coefficient, A wins. If S does and it's $a_0$ or $a_d$, S wins.\end{proposition}

    \begin{proof}A makes $p(1)$ (or $p(0)$, if $a_0$ is last) the opposite sign to $a_d$, or picks $a_d$ with the opposite sign to $a_0$; either way $p$ changes sign. S makes $a_0$, with the sign of $a_d$, so big that $p$ never vanishes, or $a_d$ big with the sign of $a_0$.\end{proof}

    When S's last coefficient is a middle one, A can still win, for instance by making $a_{d-2}$ hugely negative early on. Amog plays these by feel. Entries of $\R$ are typed as exact rationals, so the root test stays exact: it counts real roots with Sturm's theorem.

    Finite rings

    A finite ring makes a finite game, and Amog solves it with a minimax search. He plays perfectly on rings with up to 64 elements whenever the search fits in about a second; on bigger rings and positions he plays random games to the end and picks the move that won most often.     In every ring we've solved, the first player wins in even degree, just like over $\Q$, and in odd degree A wins when S moves first. But in odd degree with A first, S moving last isn't always enough: A wins cubics anyway over $\Z/3$, $\mathbb{F}_9$, $\mathbb{F}_{27}$, $\Z/8$, $\Z/16$ and $\Z/27$, and quintics over $\Z/8$ and $\Z/27$. In characteristic 3, for instance, $x \mapsto x^3$ is additive.

    Ring syntax: Z/n, F_q or GF(q) for any prime power $q \le 4096$ (built as $\mathbb{F}_p[\alpha]/(f)$ with the first irreducible $f$; type $\alpha$ as a), Z/n[t]/(f) for any letter but x (Z/n[i] is $\Z/n[i]/(i^2+1)$), products like Z/2 × F_4, and Z, Q, R, C. Values can be expressions: 2t+1, a^2, -3/4, 10^9, 1/2-i, (1, a).
