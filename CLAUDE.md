# amog.fun

Static site on Cloudflare Workers, deployed with `npx wrangler deploy` (wrangler is already OAuth'd on this machine). Pages are static assets; a small Worker (worker/index.js) runs only for /api/* (`run_worker_first`), so page loads never count as Worker requests. D1 database `amog-fun` (binding DB): add schema changes as new files in migrations/ and apply with `npx wrangler d1 migrations apply amog-fun --remote` (`--local` for wrangler dev). Secrets via `wrangler secret put`; local ones in .dev.vars (gitignored). Free plan: keep API work light (10 ms CPU per request).
Custom domains amog.fun and www.amog.fun are configured in `wrangler.jsonc`.

Conventions:
- Each project is a self-contained folder `public/<slug>/` served at `amog.fun/<slug>`. Keep projects quick & dirty and dependency-free (plain HTML/JS, CDN imports are fine).
- Games stay as paths (`amog.fun/<slug>`), not subdomains: shared assets cache once, one domain for SEO, zero per-game setup. All games share one origin, so localStorage keys MUST be prefixed `amog.<slug>.` (e.g. `amog.alchemy.v1`, `amog.nim.<variant>.score`); keep saves small (~5MB quota is shared by every game), use IndexedDB if a game needs more. Legacy exception: amog-space-program uses `asp-*` (don't rename, it would wipe saves).
- Caching lives in `public/_headers` (/assets/* = 1h + stale-while-revalidate; pages revalidate every load). Assets aren't fingerprinted, so don't set long `immutable` caching on them.
- Register every project in `public/projects.json` (slug, title, signature, blurb, tags). The landing page renders cards from it.
- `signature` is a joke morphism, e.g. `"dotsandboxes : Bored → Amused"`.
- Shared style: `/assets/amog.css` (dark starfield, Instrument Serif / STIX Two Text / JetBrains Mono, generator colors `--g1` cyan, `--g2` red, `--g3` lime). Put a `.topbar` with the `amog.fun∘` brand linking home on every page.
- Theme: Amog Magnussen is the founder & chief mathematician (group theory, category theory, obby). Copy leans into math jokes.
- LaTeX: include `<script src="/assets/math.js" defer></script>`; then `$inline$`, `$$display$$`, `\(..\)`, `\[..\]` render via KaTeX. Macros: \Hom \Cat \Grp \Set \id \op. Call `amogMath(el)` for dynamically inserted content; class `no-math` opts out. Blurbs in projects.json may use LaTeX.
- Theorem environments (same math.js): `\begin{lemma}[Title]\label{lem:x} ... \end{lemma}`, also theorem/proposition/corollary/conjecture/definition/example/remark/exercise/proof, starred = unnumbered, `\ref{lem:x}` links. Can span several <p>s. Reference + demo page: amog.fun/latex (public/latex/). Not listed in projects.json.
- math.js extras: `notation` env; `\N \Z \Q \R \C` built in; per-page macros via `<script type="text/tex-preamble">\def\im{\operatorname{im}}</script>`; tikz-cd diagrams (diagonals, bends, dashes, labels) via `<script type="text/tikzcd">...</script>` (KaTeX `CD` only does square grids). Documented on amog.fun/latex.
- amog.fun/blog (public/blog/): Amog's math notes. One folder per post (`public/blog/<slug>/index.html`, shared `blog.css`), listed newest-first by hand in `public/blog/index.html`, and linked prev/next via `.post-nav`. Posts are converted from the authors' LaTeX: keep their text, map envs to math.js (`<div data-env=...>` inside `<section data-section=N>`), `\vocab{}` -> `<b class="vocab">`, solutions as `<details class="sol">` with difficulty stars. Unfinished posts get the "work in progress" badge + `.wip` note. Typo/math fixes are listed for airetho in a GitHub issue rather than made silently.
- Paper-style numbering: wrap sections in `<section data-section="2">` to get Lemma 2.1, Remark 2.2, ... (shared counter per section). Also `question` env, and `data-qed="□"` on an ancestor to change the proof symbol. Display equations auto-shrink (≥72%) to fit narrow screens.
- drafts/thesis/: Amog's parody paper (paper layout using the LaTeX envs + `.paper` light-sheet scope). Deliberately NOT deployed (privacy: it identifies Amog). Never move it into public/ or link to it.
- amog.fun/alchemy (public/alchemy/): SkyFactory-style skyblock crafting/idle game. **All items, recipes, drop tables, smelting, quests and balance live in `data.js`** (Amog's recipes go there; the format is documented at the top of the file). engine.js is pure logic (no DOM, runs in Node); ui.js/panels.js/island.js render; icons.js draws pixel icons procedurally from each item's `icon: [shape, color, extra]`. After changing data.js, sanity-check that the chain is still completable: `node tools/alchemy/bot.mjs` plays engine.js from a fresh island to the Terminal Object (exit 1 if stuck). Saves are in localStorage key `amog.alchemy.v1` (schema `s.v`, migrated in engine.js `revive`; bump it when tile/state shapes change). Furnace-like machines are STATIONS in engine.js (furnace + alloy smelter share fuel); auto machines (data.js `AUTO`) each hold their own tool. Buildings are inventory items: crafting puts them in `s.inv`, `place`/`pickUp`/`move` put them on and off the island (`count` = owned, `built` = placed). Clicking a building opens its machine panel (panels.js `machineBody`); there is no Machines card. Land is never bought: every completed quest adds a tile (`CONFIG.land`, engine `growLand`); don't reintroduce land or barrel costs. Tables and furnace-like machines can auto-make one item each once the Automation quest is done (`setAuto`). The Wilds (wilds.js; data `AREAS`/`MOBS`, `CONFIG.combat`/`pasture`/`enchant`/`grinder`) are areas that cost no tiles: Dark Platform combat with swords/armor/XP, the cow pasture, enchanting (`CONFIG.enchant.types`: Sharpness/Protection/Efficiency per tool kind plus mesh Efficiency/Fortune; applies to slotted tools too; past V costs ghast tears), and the Nether. Monsters unlock by peak level (`peakLevel`), never current level. One click crafts at most `CONFIG.craftMax` (64). Auto-make has a limit or `uncapped` (engine `autoLimit`). Pasture herds: cows come with it, sheep are lured (`CONFIG.pasture.sheep`, engine `HERDS`/`breed(s, kind)`). Late-game recipes use steel blocks. island.js caches the static scene and redraws on requestAnimationFrame; call its requestDraw, don't draw per game tick.

- amog.fun/amog-space-program (public/amog-space-program/): the Amog Space Program rocket incremental, ported from ErhaiYKao/erhaiykao.github.io, overhauled to v2 (airetho's issue). Balance (engines, research, missions, contracts, stars) lives in js/data.js; js/game.js is pure logic (runs in Node). Save key stays `asp-save-v1` with a schema field `v` (v1 saves migrate in game.js `sanitizeState`/`migrateV1`; bump `SAVE_VERSION` and migrate when the state shape changes). Tests: node --test tools/amog-space-program/asp.test.mjs. Balance: node tools/amog-space-program/balance-sim.mjs [--quick] prints physics sanity, a capability table (missions each tech tier opens — keep it ≤3) and a progression timeline from bot.mjs, which plays game.js headless. Economy rule: launch hardware is paid out of the flight's earnings and capped at half of them (game.js `flightNet`), never up front, so a player can never go broke and every flight keeps ≥50% of its payout; keep hardware a minority of what a good rocket at each tier earns (tested; airetho's playtest hit $440k hardware vs $10k rewards). Feedback button opens issues on ErhaiYKao/amog-fun.
- amog.fun/axis-order-incremental: the last version (Jul 2026, "AXIS ORDER — Ascendancy") of Axis Order, recovered from an overwritten commit in ErhaiYKao/erhaiykao.github.io-archive. Single self-contained file; saves are manual export strings.
- amog.fun/nim (public/nim/): Nim family. kit.js = shared engine (turns, perfect AI via isP, hints, scores); each variant (index.html = classic, fibonacci/, wythoff/, kayles/, staircase/, northcott/, subtraction/, hackenbush/ (partizan: isP depends on who)) supplies create/moves/apply/isP/render/math, plus optional custom.parse for the "custom start" box and symmetric(s) (mirrored positions Amog avoids). AI levels live in kit.js: novice looks 2 plies ahead (take instant wins, avoid giving them), Amog plays perfectly, prefers non-mirrored winning moves, and when losing leaves the fewest winning replies. Add a variant: new folder + entry in VARIANTS in kit.js. Theory sections are spoilers: keep h2 generic ("Why Amog always wins"), put the revealing title in an h3, and keep sigs/meta descriptions hint-free.
- amog.fun/coin-flips (public/coin-flips/): Coin Flip Court, airetho's randomness-tester trinket (#17). stats.js is pure (runs in Node): each test reports both tails P(X≥x), P(X≤x) under fair flips, exact via binomial / run-length and random-walk DPs that accumulate mass (never 1−tiny), seeded Monte Carlo for palindromes and pattern counts (marked sim; sim can't go below 1/(sims+1), so far palindrome tails use palBound, a union bound that's tight once small, marked bound). Dice mode (d3–d9, `analyseDice`, ≤1000 rolls): sum/spread/jump convolutions, face-count DP, repeats, runs. Add a test in `analyse`/`analyseDice` plus its phrasing in WORDS in index.html. Tests: node --test tools/coin-flips/stats.test.mjs (brute-force enumeration check).
- amog.fun/omegamac (public/omegamac/): zetamac-style mental math trainer (airetho's #19). gen.js is pure (runs in Node): TYPES (id, section, KaTeX def, bound fields R/V, gen → {args, tex, plain, answer}), PRESETS, the smart number-theory picker (weight d(n)^2 for one-input types, common factor g weighted g·(m−2) for gcd/lcm, 15% uniform), and the settings codec (`d=120&add&mul=2-12-2-200&n=Name`, params only when non-default; typesKey = preset identity). Capped types (pow/log/perm/comb) return null when nothing fits and next() skips them. index.html is the UI; localStorage `amog.omegamac.v1` = {presets, scores keyed `d|typesKey`, last}. Add a type: entry in TYPES plus a BRUTE/BOUNDS check in the test (changing a built-in preset's types or default bounds changes its leaderboard's problems: old scores stay but are for a different game). Types with a `help` string show it under the playfield when they come up. Skip (Space or button) costs SKIP_MS of the clock and is logged as a null answer. Leaderboard: see "Leaderboards" below; worker/omegamac.js replays answers through gen.js (ranked = built-in preset at a DURATIONS length). Tests: node --test tools/omegamac/*.test.mjs.
- amog.fun/fermimac (public/fermimac/): estimation zetamac (Not The Pope Log's #20). gen.js is pure (Node + Worker): PRESETS (feynman = math within 10%, sharp = 2%, fermi = world questions within ×2), MATH generators, the FERMI bank ([question, answer], mid-2020s values), PI/NTH tables (sieve-checked in tests), parseGuess (1e3, 4.2×10^3, 4.2k, 1.5M, 2bn…). makeRun(preset, seed).next() deals problems independent of guesses (one guess each), so the server replays by seed. Tests: node --test tools/fermimac/gen.test.mjs.
- amog.fun/coefficient-game (public/coefficient-game/): the Coefficient Choosing Game (Not The Pope Log's #22). ring.js is pure (page, Node and Worker): parseRing (Z/n, F_q, Z/n[t]/(f), products, Z, Q, R, C; see its header for limits), element parse/show (show parses back), root tests (finite: every element; Z/Q: Sturm isolation + the one rational candidate per interval; R: Sturm count, entries are exact rationals; C: always), and the rules (newGame/play/moveError). amog.js is computer Amog: exact minimax for finite rings ≤ 64 elements within a work budget, otherwise playouts ending in a direct last-move search; `verdict` powers the hint button. The theory table in index.html was computed with the solver (rerun it if you change rules). Online: worker/coefficients.js, one Durable Object (`CoeffRoom`, binding ROOMS, SQLite-backed so it's free) per room with hibernating WebSockets; it referees with ring.js; seat tokens in localStorage `amog.coefficient-game.seats`. Tests: node --test tools/coefficient-game/ring.test.mjs (axioms, root tests vs brute force, solver vs naive minimax).
- Leaderboards (Omegamac, Fermimac): worker/leaderboard.js is shared (tokens, timing checks, D1 lb_runs/lb_best keyed by game, board, dur); each game's worker/<game>.js exports {id, presets, durations, minGap, verify} and is registered in GAMES in worker/index.js. /api/<game>/start returns an HMAC-signed token (secret OMEGAMAC_SECRET) with the seed; the page plays from mulberry32(seed); /submit replays and checks real elapsed time, gaps, expiry, one submit per run id; best score per name (case-insensitive) per board. Client: /assets/lb.js (AmogLB); the player's name is shared across games in localStorage `amog.lb.name`. Changing a ranked preset's problems changes what its board measures. Names (worker/names.js), checked after the replay and before the run id is spent: a rot13 wordlist after undoing leetspeak/accents/stretching (short words match whole words only, for Scunthorpe), then Workers AI (binding AI, `MODEL`) once per new name, verdict cached in D1 lb_names; fails open and uncached if the model is down. A refused name returns {name: true} and lb.js asks for another for the same run. Moderation: worker/admin.js with `Authorization: Bearer <ADMIN_SECRET>`: GET /api/admin/names, POST /api/admin/block|allow {name} (block deletes their scores everywhere; an admin verdict beats wordlist and model). Tests: tools/omegamac/names.test.mjs.
