# amog.fun

Static site on Cloudflare Workers (assets only), deployed with `npx wrangler deploy` (wrangler is already OAuth'd on this machine).
Custom domains amog.fun and www.amog.fun are configured in `wrangler.jsonc`.

Conventions:
- Each project is a self-contained folder `public/<slug>/` served at `amog.fun/<slug>`. Keep projects quick & dirty and dependency-free (plain HTML/JS, CDN imports are fine).
- Games stay as paths (`amog.fun/<slug>`), not subdomains: shared assets cache once, one domain for SEO, zero per-game setup. All games share one origin, so localStorage keys MUST be prefixed `amog.<slug>.` (e.g. `amog.alchemy.v1`, `amog.nim.<variant>.score`); keep saves small (~5MB quota is shared by every game), use IndexedDB if a game needs more. Legacy exception: amog-space-program uses `asp-*` (don't rename, it would wipe saves).
- Caching lives in `public/_headers` (/assets/* = 1h + stale-while-revalidate; pages revalidate every load). Assets aren't fingerprinted, so don't set long `immutable` caching on them.
- Register every project in `public/projects.json` (slug, title, signature, blurb, tags). The landing page renders cards from it.
- `signature` is a joke morphism, e.g. `"dotsandboxes : Bored → Amused"`.
- Shared style: `/assets/amog.css` (dark starfield, Instrument Serif / STIX Two Text / JetBrains Mono, generator colors `--g1` cyan, `--g2` red, `--g3` lime). Put a `.topbar` with the `amog.fun∘` brand linking home on every page.
- Theme: Amog Magnussen is the founder & chief mathematician (group theory, category theory, obby). Copy leans into math jokes.
- LaTeX: include `<script src="/assets/math.js" defer></script>`; then `$inline$`, `$$display$$`, `\(..\)`, `\[..\]` render via KaTeX. Macros: \Hom \Cat \Grp \Set \id \op. Call `amogMath(el)` for dynamically inserted content; class `no-math` opts out. Blurbs in projects.json may use LaTeX.
- Theorem environments (same math.js): `\begin{lemma}[Title]\label{lem:x} ... \end{lemma}`, also theorem/proposition/corollary/conjecture/definition/example/remark/exercise/proof, starred = unnumbered, `\ref{lem:x}` links. Can span several <p>s. Reference + demo page: amog.fun/latex (public/latex/). Not listed in projects.json.
- math.js extras: `notation` env; `\N \Z \Q \R \C` built in; per-page macros via `<script type="text/tex-preamble">\def\im{\operatorname{im}}</script>`; tikz-cd diagrams (diagonals, bends, dashes, labels) via `<script type="text/tikzcd">...</script>` (KaTeX `CD` only does square grids). Documented on amog.fun/latex.
- amog.fun/blog (public/blog/): Amog's math notes. One folder per post (`public/blog/<slug>/index.html`, shared `blog.css`), listed newest-first by hand in `public/blog/index.html`, and linked prev/next via `.post-nav`. Posts are converted from the authors' LaTeX: keep their text, map envs to math.js (`<div data-env=...>` inside `<section data-section=N>`), `\vocab{}` -> `<b class="vocab">`, solutions as `<details class="sol">` with difficulty stars. Unfinished posts get the "work in progress" badge + `.wip` note. Typo/math fixes are listed for airetho in a GitHub issue rather than made silently.
- Paper-style numbering: wrap sections in `<section data-section="2">` to get Lemma 2.1, Remark 2.2, ... (shared counter per section). Also `question` env, and `data-qed="□"` on an ancestor to change the proof symbol. Display equations auto-shrink (≥72%) to fit narrow screens.
- drafts/thesis/: Amog's parody paper (paper layout using the LaTeX envs + `.paper` light-sheet scope). Deliberately NOT deployed (privacy: it identifies Amog). Never move it into public/ or link to it.
- amog.fun/alchemy (public/alchemy/): SkyFactory-style skyblock crafting/idle game. **All items, recipes, drop tables, smelting, quests and balance live in `data.js`** (Amog's recipes go there; the format is documented at the top of the file). engine.js is pure logic (no DOM, runs in Node); ui.js/panels.js/island.js render; icons.js draws pixel icons procedurally from each item's `icon: [shape, color, extra]`. After changing data.js, sanity-check that the chain is still completable: `node tools/alchemy/bot.mjs` plays engine.js from a fresh island to the Terminal Object (exit 1 if stuck). Saves are in localStorage key `amog.alchemy.v1` (schema `s.v`, migrated in engine.js `revive`; bump it when tile/state shapes change). Furnace-like machines are STATIONS in engine.js (furnace + alloy smelter share fuel); auto machines (data.js `AUTO`) each hold their own tool. Buildings are inventory items: crafting puts them in `s.inv`, `place`/`pickUp`/`move` put them on and off the island (`count` = owned, `built` = placed). Clicking a building opens its machine panel (panels.js `machineBody`); there is no Machines card.
- Git: this repo is public at github.com/ErhaiYKao/amog-fun. Commit and push only as ErhaiYKao (local git config + credential helper are already set). Never commit as the owner's personal account, and never add personal info, local paths, credentials or .env files.
- amog.fun/amog-space-program (public/amog-space-program/): the Amog Space Program rocket incremental, ported from ErhaiYKao/erhaiykao.github.io, overhauled to v2 (airetho's issue). Balance (engines, research, missions, contracts, stars) lives in js/data.js; js/game.js is pure logic (runs in Node). Save key stays `asp-save-v1` with a schema field `v` (v1 saves migrate in game.js `sanitizeState`/`migrateV1`; bump `SAVE_VERSION` and migrate when the state shape changes). Tests: node --test tools/amog-space-program/asp.test.mjs. Balance: node tools/amog-space-program/balance-sim.mjs [--quick] prints physics sanity, a capability table (missions each tech tier opens — keep it ≤3) and a progression timeline from bot.mjs, which plays game.js headless. Economy rule: launch hardware is paid out of the flight's earnings (net = max(0, payout − hardware)), never up front, so a player can never go broke or get locked out; keep every first-stage engine with a profitable single-stage design (tested). Feedback button opens issues on ErhaiYKao/amog-fun.
- amog.fun/axis-order-incremental: the last version (Jul 2026, "AXIS ORDER — Ascendancy") of Axis Order, recovered from an overwritten commit in ErhaiYKao/erhaiykao.github.io-archive. Single self-contained file; saves are manual export strings.
- amog.fun/nim (public/nim/): Nim family. kit.js = shared engine (turns, perfect AI via isP, hints, scores); each variant (index.html = classic, fibonacci/, wythoff/, kayles/, staircase/, northcott/, subtraction/, hackenbush/ (partizan: isP depends on who)) supplies create/moves/apply/isP/render/math, plus optional custom.parse for the "custom start" box. Add a variant: new folder + entry in VARIANTS in kit.js. Theory sections are spoilers: keep h2 generic ("Why Amog always wins"), put the revealing title in an h3, and keep sigs/meta descriptions hint-free.
